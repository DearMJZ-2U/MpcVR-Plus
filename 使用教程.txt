一、怎么打开设置页
--------------------------------------------------------
  播放视频时，在画面上点右键 →「滤镜」→「MPC Video Renderer」，
  就会弹出设置窗口。窗口顶部有两个页签：
      「设置」  常用选项（默认打开这一页）
      「信息」  当前实际生效的能力、运行库状态、构建标识

  小技巧：界面里绝大多数控件把鼠标停上去，都会弹出一段中文说明，
  写着「这是什么 / 怎么用 / 注意什么」。不确定某一项时，先悬停看一眼。


二、设置页各分区说明
--------------------------------------------------------
  【顶部一行】
      使用 Direct3D 11   渲染走 D3D11 路径（默认开，DLSS 补帧需要它）
      纹理格式           自动 8/10 位整型 / 8 位整型 / 10 位整型 / 16 位浮点
      显示统计信息       在画面左上角叠加实时统计（也可用统计字体方式）
      右侧下拉框         统计信息的字体显示方式

  【DXVA2 与 D3D11 视频处理器】
      用于:              NV12 / P010/P016 / YUY2 / 其他支持的格式
                         决定哪些像素格式交给显卡的视频处理器处理
      反交错             禁用 / 启用 / HACK 倍频
      反交错时输出倍频
      用于缩放
      请求超分           这是 MPCVR 原版的「RTX 视频超分」，靠显卡驱动实现：
                         禁用 / 仅 SD / ≤720p / ≤1080p / ≤1440p
                         （含义：片源分辨率不超过该档位时才请求驱动超分）
                         ★ 它与下面的「超分算法」是两个不同的功能，二选一
       RTX 视频 HDR      由显卡驱动把 SDR 视频实时转成 HDR 输出

  【着色器视频处理器】
      色度上采样         最近邻 / 双线性 / Catmull-Rom
      放大算法           最近邻 / Mitchell-Netravali / Catmull-Rom /
                         Lanczos2 / Lanczos3 / Jinc2m
      缩小算法           同上
      用"放大"算法将帧缩小至 50%
      使用抖动
      YUV 4:2:0 使用混合反交错

  【HDR】
      Dolby Vision 优先于 PQ/HLG
      HDR10/DV           HDR 处理方式（直通 / 转换等），旁边可填显示尼特数
      Windows HDR        跟随系统 / 允许开 / 允许关（全屏）
      字幕与 OSD 亮度    滑块，调 HDR 下字幕和 OSD 的亮度
      HDR 直通不可用或已禁用时：转换为 SDR
      SDR 显示亮度       滑块

  【右下角】
      交换模式           交换链呈现方式
      使用独占全屏
      呈现前等待垂直同步
      调整帧呈现时间
      显示器变更时重建设备
      「默认」按钮        把这一页恢复成默认值

  【超分算法】          关闭 / FSR 3.1 / DLSS SR      ← 见第四节
  【补帧（实验）】      倍率 + 补帧方式              ← 见第三节

  【最底部一行】        状态行，显示当前「超分 / 补帧」的实际状态，
                        以及该补帧方式支持的最高倍率。内容放不下时会自动
                        精简；鼠标停上去可看完整内容。


三、补帧：怎么开、怎么选后端和倍率
--------------------------------------------------------
  补帧 = 帧生成，把视频帧率翻倍。例如 24fps 的片源，6X 后是 144fps。

  操作顺序：
    1) 先在「补帧（实验）」分组里，用右边的「补帧方式」下拉框选后端：
         NVIDIA DLSS 帧生成            倍率 2X~6X    需 RTX 40/50
         NVIDIA VFG 帧生成             倍率 2X~8X    需 RTX 40/50
         AMD FSR 3.1 · 2X              倍率 2X       各品牌显卡都能用
         Intel XeSS                    倍率 2X~4X    各品牌显卡都能用
         AMD FSR 4 ML 帧生成 · 2X（未验收）  倍率 2X   不建议使用
    2) 再在左边的倍率单选里选倍率：关 / 2X / 3X / 4X / 5X / 6X / 7X / 8X
       倍率超过所选后端的上限时，会被自动收敛到该后端的最高值；
       某些后端下超范围的档位会直接变灰。

  各后端的说明（属性页里悬停「补帧方式」也有同样内容）：
    · DLSS 帧生成     NVIDIA 官方技术，画质最好，需要 RTX 40 系或更新。
    · NVIDIA VFG      NVIDIA Video Effects SDK 的帧生成，倍率能到 8X。
    · FSR 3.1         AMD 的算法，NVIDIA / AMD / Intel 显卡都能用，只到 2X。
    · Intel XeSS      Intel 的补帧技术。Intel 显卡上支持最完整，但
                      NVIDIA / AMD 显卡也能用；Intel 官方只到 2X，
                      本插件强化可到 4X。非 Intel 显卡上限通常更低，
                      常见只到 2X（选高了会被自动压回）。
    · FSR 4 ML 帧生成 AMD 的机器学习帧生成，目前未验收，默认不建议使用。

  ★ 关于 7X / 8X：
      这两个档位只有「NVIDIA VFG」后端能选，属于实验档位。
      实测在常见显卡上 7X 的帧率和 6X 基本相同、8X 反而更低，
      所以画质/流畅度不会有额外提升。日常建议用 4X 或 6X。

  怎么确认补帧真的在工作：
      开「显示统计信息」，看画面上的帧率是否上升；
      或者看日志 %LOCALAPPDATA%\MpcVR-DLSS\logs\fg.log，
      出现 "StartFg: ACTIVE" 就是补帧已启动。

  注意：
    · 补帧吃显卡性能。固定刷新率屏幕上，4X 和 6X 帧率一样，说明显卡到顶了。
    · 片源本身帧率越低，补帧效果越明显；60fps 片源再插帧意义不大。


四、超分：两种「超分」别搞混
--------------------------------------------------------
  属性页里有两个地方写着「超分」，它们是不同的功能：

    (1)「请求超分」—— 在【DXVA2 与 D3D11 视频处理器】分组里
        这是 MPCVR 原版功能，走显卡驱动的视频处理器扩展实现，
        相当于 NVIDIA 控制面板里的「RTX 视频超分」。
        只在片源分辨率不超过所选档位时触发。

    (2)「超分算法」—— 独立的「超分算法:」下拉框
        关闭 / FSR 3.1 / DLSS SR
        这是把低分辨率画面用 AI 放大到输出分辨率，属于本插件新增的能力。
          FSR 3.1   AMD 的算法，NVIDIA / AMD / Intel 显卡都能用
          DLSS SR   NVIDIA 的算法，需要 RTX 显卡

  使用要点：
    · 「超分算法」和「请求超分」互斥：一旦「超分算法」选了非「关闭」，
      「请求超分」会自动变灰，避免同一帧被放大两次。
    · 「超分算法」只在画面确实被放大时才生效。
      如果你播放的是 1080p 片源、窗口也是 1080p，就没有放大动作，
      超分自然不生效。想看效果请把窗口最大化，或播放低分辨率片源。
    · 可以和补帧同时开启，状态行会显示「两者可同时开启」。
    · 例外：用 Intel XeSS 补帧时，「超分算法」会自动变灰、不生效
      （XeSS 补帧自己接管了输出，状态行会提示）。
    · 灰色的控件不响应鼠标，因此也不会弹出提示，这是正常现象。


五、HDR：怎么开
--------------------------------------------------------
  1. 先在 Windows 里打开 HDR：
     设置 → 系统 → 显示 → HDR
  2. 在属性页【HDR】分组里：
     · 把「HDR10/DV」设成直通（Passthrough）
     · 需要的话勾上「Dolby Vision 优先于 PQ/HLG」
     · 根据显示器填写尼特数（默认 1000）
  3. 只有上面两步都满足时，【DXVA2 与 D3D11 视频处理器】分组里的
     「RTX 视频 HDR」才能勾选（由显卡驱动把 SDR 视频实时转 HDR）。
  4. 如果不想用 HDR 直通，可以勾「转换为 SDR」，并调「SDR 显示亮度」。
  5. HDR 下如果觉得字幕/OSD 太暗或太亮，用「字幕与 OSD 亮度」滑块调整。


六、统计信息与信息页
--------------------------------------------------------
  统计信息
      在属性页勾选「显示统计信息」，画面左上角会出现实时统计。
      （另外 PotPlayer 自带的信息 OSD 也可以按 Tab 呼出。）

  「信息」页（属性页顶部的第二个页签）
      这里显示当前实际生效的情况，排查问题很有用：
        · 请求的补帧方式 / 实际生效的后端
        · 各后端的原生倍率上限
        · 超分状态
        · 运行库是否就位（每一项的检测结果）
        · 构建标识（BuildId，本包为 a37f5bec9b40a44f）

      如果某项功能显示「不可用」，这里会写明原因
      （例如运行库缺失、显卡不支持等），不会静默换成别的后端。


七、性能与调优建议
--------------------------------------------------------
  · 补帧倍率越高越吃性能。建议从 2X 开始，逐步往上试，找到稳定的最高档。
  · 固定刷新率屏幕上，如果 4X 和 6X 的帧率一样，说明显卡性能到顶了，
    继续调高不会更快，建议就用能稳定跑满的那一档。
  · 开启「硬件加速 GPU 计划 (HAGS)」通常能让补帧更稳：
    设置 → 系统 → 显示 → 图形 → 默认图形设置。
  · 4K 输出对显卡压力很大；分辨率越高，能达到的补帧倍率越低。
  · 首次进入全屏时，渲染器可能会重建一次交换链，画面闪一下，属正常现象。


八、常见问题
--------------------------------------------------------
  Q1. 补帧没生效？
      依次检查：
        ① 是否已经选了「补帧方式」和倍率（倍率不能是「关」）
        ② 显卡是否满足该后端的要求（DLSS-G / VFG 需 RTX 40/50）
        ③ 是否开启了 HAGS
        ④ 看日志 %LOCALAPPDATA%\MpcVR-DLSS\logs\fg.log：
             - 出现 "StartFg: ACTIVE"        说明补帧已工作
             - 出现 "runtime unavailable ..." 说明运行库没找到
             - 出现 "DLSS-G unavailable"      说明显卡/驱动不满足
        ⑤ 属性页「信息」页会直接写明不可用的原因

  Q2. 播放卡顿 / 掉帧？
      先把补帧设为「关」，确认基础播放正常；再把倍率降一档（如 6X 降到 4X）。
      这是显卡性能问题，不是 bug。

  Q3. 画面花屏 / 撕裂？
      关掉补帧看看是否恢复；也检查「呈现前等待垂直同步」「使用独占全屏」
      这两项的组合。多数是显示模式/刷新率不匹配导致。

  Q4. 超分选了却没效果？
      「超分算法」只在画面确实被放大时才生效。
      请播放低分辨率片源，或把窗口/全屏分辨率调得高于片源分辨率。
      另外确认没有开 XeSS 补帧（开 XeSS 补帧时超分会被禁用）。

  Q5. HDR 选项是灰的？
      需要同时满足：Windows 已开启 HDR、且「HDR10/DV」设为直通。

  Q6. 字幕或 OSD 显示异常？
      本包的字幕与 OSD 合成方式已和内置 D3D11 渲染器对齐。
      若仍有问题，请附上 logs\fg.log 和问题截图。

  Q7. 换了显示器 / 换了电脑，设置丢了？
      渲染器设置保存在 HKCU\Software\MPC-BE Filters\MPC Video Renderer，
      重装 PotPlayer 不会清掉它。如果换电脑，重跑一次 install.cmd 即可。

  Q8. 想恢复默认设置？
      在属性页点右下角的「默认」按钮。
